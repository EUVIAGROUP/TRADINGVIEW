# Как показать NEURO другу

Подготовлен постоянный HTTPS-адрес через ваш аккаунт ngrok. Сайт работает на вашем ПК; ngrok доставляет к нему запросы из интернета. Домен покупать и порты роутера открывать не требуется. Пока аккаунт не настроен, публичная ссылка не работает.

## Первый запуск

1. Зарегистрируйтесь или войдите на https://dashboard.ngrok.com/signup.
2. Откройте `D:\NEURO SCREENER\SETUP_HTTPS.cmd` двойным щелчком.
3. Вставьте выданный вам адрес из https://dashboard.ngrok.com/domains. Это публичный адрес, а не секрет.
4. Вставьте только токен из https://dashboard.ngrok.com/get-started/your-authtoken. В окне ввода символы не показываются. Не присылайте токен в чат. Настройка хранит его зашифрованным Windows DPAPI для вашего пользователя Windows, отдельно от проекта.
5. Запустите `D:\NEURO SCREENER\START_HTTPS.cmd`. Дождитесь сообщения «Сайт доступен по HTTPS». При успехе ссылка появится в `SHARE_URL.txt` в папке проекта. Отправьте её другу самостоятельно.

Друг открывает ссылку, проходит информационную страницу ngrok и создаёт собственный аккаунт NEURO либо входит в свой существующий. Пароль от вашего аккаунта ему не нужен. Вход и данные аккаунтов общие с ботом; настройки друга сохраняются для его аккаунта.

При ошибке запуска откройте `STATUS_HTTPS.cmd`. Подробности находятся в `data\hosting\server.log` и `data\hosting\ngrok.log`. Если ngrok сообщает об ошибке токена или домена, проверьте аккаунт и повторите `SETUP_HTTPS.cmd`. Не отключайте антивирус для запуска.

## Управление сервером

| Файл в D:\NEURO SCREENER | Действие |
|---|---|
| SETUP_HTTPS.cmd | Указать адрес и токен аккаунта |
| START_HTTPS.cmd | Запустить сайт и HTTPS-туннель; окно оставить открытым |
| STOP_HTTPS.cmd | Остановить внешний доступ; обычный локальный сервер продолжит работать |
| STATUS_HTTPS.cmd | Посмотреть состояние запуска |
| ENABLE_HTTPS_AUTOSTART.cmd | Включить фоновый запуск после входа вашего пользователя в Windows |
| DISABLE_HTTPS_AUTOSTART.cmd | Выключить этот автозапуск |
| PUBLIC_SITE.url | Открыть настроенный адрес; создаётся после настройки |
| SHARE_URL.txt | Ссылка для друга; создаётся после успешной проверки HTTPS |

Автозапуск пока не включён. Сначала настройте аккаунт и проверьте ручной запуск. Автозапуск срабатывает после входа в Windows, а не до входа пользователя. При остановке процесса или ошибке запуска нужно снова открыть START_HTTPS.cmd; ngrok самостоятельно восстанавливает кратковременные обрывы соединения, пока его процесс работает.

## Чтобы ПК работал сервером

- ПК должен быть включён и подключён к интернету. Сон, выключение и отсутствие интернета делают сайт недоступным.
- При необходимости в настройках питания Windows отключите автоматический сон при питании от сети. Настройки питания не менялись автоматически.
- Один и тот же адрес ngrok остаётся закреплён за аккаунтом. Это не гарантирует круглосуточную доступность самого ПК.
- Для работы без включённого домашнего ПК сайт позднее можно перенести на VPS.

## Что настроено

Локальный сайт остаётся на 127.0.0.1:8765. Внешний экземпляр слушает только 127.0.0.1:8766; ngrok предоставляет HTTPS с действительным сертификатом. Соединение от ngrok до приложения внутри этого ПК — локальный HTTP. Сертификат на localhost не устанавливался.

Сервер принимает только точный публичный адрес, проверяет Origin и HTTPS-заголовок локального прокси. Для внешнего режима включён Secure у cookies. Данные сессий внешнего входа отделены от локальных. Захват содержимого запросов в локальном инспекторе ngrok выключен. Проверки на отдельной временной базе: 12 из 12 пройдены; реальные аккаунты в тестах не изменялись. ngrok 3.39.11 скачан с сайта производителя, цифровая подпись «ngrok, Inc.» проверена.

Бесплатный ngrok имеет лимиты и промежуточную страницу для посетителей; адрес выдаётся сервисом и не выбирается произвольно. [Официальные ограничения](https://github.com/ngrok/ngrok-docs/blob/main/pricing-limits/free-plan-limits.mdx), [установка ngrok для Windows](https://ngrok.com/download/windows?tab=install).
