# NEURO Screener

Локальный сайт: http://127.0.0.1:8765

## Запуск

Откройте START_NEURO.cmd. Используется готовый Python из TG BOTE. Сервер слушает только этот компьютер. Для постоянной работы окно сервера должно оставаться открытым. Не запускайте вторую копию на том же порту.

## Общий аккаунт

Войдите логином и паролем из Telegram-бота или зарегистрируйтесь на сайте. Логины общие и уникальны без учёта регистра. Пароли 10–128 символов хранятся как scrypt-хеш. Новому веб-аккаунту назначается внутренний отрицательный ID. Чтобы включить Telegram-доставку, войдите в существующий аккаунт через /start в боте; бот переносит профиль на Telegram ID. После переноса войдите на сайт заново. Блокировки аккаунта применяются и на сайте.

## Работает

- Рассвет / день / закат / ночь по местным часам компьютера и вручную; прокрутка с параллаксом, окна, транспорт, адаптация для телефона, reduced-motion.
- Общая регистрация и вход; серверные сессии 12 часов, HttpOnly/SameSite cookies, проверка Origin/Host, ограничение попыток входа.
- Каталог из базы бота: биржа, категория, тип рынка, поиск. До 250 строк в выборке.
- Настоящие свечи публичных API шести бирж, график и индикаторы движка бота. Кэш 30 секунд, время получения показано. Данные обновляются по запросу.
- «Сканировать 12» проверяет первые 12 инструментов текущей выборки и выбранный интервал, не весь каталог.
- Избранное, RSI / EMA / KDJ, направления, свечи, биржи и интервалы фонового сканирования, ценовые алерты и история сохранённых сигналов общие с ботом.
- Состояния подключений, заявок и сопровождения без выдачи API-ключей в браузер.

## Границы версии

Сайт не размещён в интернете. Для публикации нужны HTTPS, отдельная конфигурация адресов/cookies, постоянный сервер и эксплуатационная проверка. Текущий запуск предназначен только для localhost.

Это нейрофутуристический интерфейс с индикаторами; нейросетевая модель прогнозирования не подключена. Точный видеореференс YouTube не удалось получить, визуализация города создана по описанию.

Отправку алертов и фоновое сканирование выполняет запущенный TG BOTE. Сайт не запускает второй Telegram polling. Торговые операции, управление ролями, паролями, расширенное оформление графиков и служебные команды остаются в Telegram. Веб-сайт не является полным переносом всех меню бота.

## Данные и архитектура

server.py — aiohttp, static/ — интерфейс без сборщика и внешних CDN. Используются текущие модули bot.models, bot.storage и bot.services; изменения этих модулей могут требовать обновления адаптера сайта.

Общая база: D:\TG BOTE\data\bot.sqlite3. Сайт не выполняет миграции схемы бота. Записывает только действия зарегистрированного пользователя в существующие таблицы users/chats/watchlist/price_alerts/audit. Веб-сессии: data/web.sqlite3. Секреты бирж и токен Telegram не копируются. Для чтения сохранённых сигналов используется локальный ключ шифрования бота, который не передаётся клиенту.

Переменные окружения для тестов/другой установки: NEURO_BOT_DIR, NEURO_BOT_DB, NEURO_WEB_DB. Порт 8765, допустимые адреса localhost и 127.0.0.1.

Проверка: runtime Python бота запускает test_server.py. Тесты используют только временную копию схемы, не живые учётные записи.
